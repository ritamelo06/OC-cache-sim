# OC-cache-sim
Lab1 Assignment: Simple Cache Simulator

Exercises:
1. Direct-Mapped L1 Cache – Implements a direct-mapped L1 cache using parameters from the constants file.
2. Direct-Mapped L2 Cache – Adds a direct-mapped L2 cache to form a two-level hierarchy.
3. 2-Way Set-Associative L2 Cache – Modifies the L2 cache to a two-way set-associative design.
